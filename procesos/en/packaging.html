Packaging

Dry pellets are weighed and sealed into bags. Each bag is labelled with its origin lot code. Any auditor can scan that code and rebuild the full lineage.

Packaging & labelling Floor operator ~5 min per bag Traceability printed

In simple

Each bag is filled to weight, sealed and labelled with a unique code. That code is the lot's identity document.

In detail

The operator uses a calibrated scale and a thermal sealer. The system prints the label on site with the lot code, packaging date and origin lot. The scale rejects any bag outside the allowed range (±25 g on a 25 kg target) — those bags go back into the flow and never leave the warehouse. The thermal seal includes a QR code that points to a URL with the full traceability tree (when client+server is in production).
