Proceso 05 / 07

Envasado

Los pellets secos se pesan y sellan en sacos. Cada saco se etiqueta con el código del lote de origen. Cualquier auditor puede escanear ese código y reconstruir el linaje completo.

Envasado y etiquetado Operario de planta ~5 min por saco Trazabilidad impresa

En simple

Cada saco se llena con la cantidad exacta, se sella y se rotula con un código único. Ese código es el documento de identidad del lote.

En detalle

El operario trabaja con una balanza calibrada y una selladora térmica. El sistema imprime la etiqueta in situ, con el código del lote, fecha de envasado y lote origen. La balanza rechaza cualquier saco fuera del rango permitido (±25 g sobre cible de 25 kg) — esos sacos vuelven al flujo, no salen al almacén. El sello térmico incluye un código QR que apunta a una URL con el árbol de trazabilidad completo (cliente → servidor cuando esté en producción).
